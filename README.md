# Natural Farming Vietnam Public Website

Next.js public site song ngữ, đọc site settings và workshop đã publish từ Django backend.

Tài liệu canonical:

- route, localization, data flow, cache, SEO và UI: [`../docs/public-frontend.md`](../docs/public-frontend.md);
- setup local, quality gate và deploy: [`../docs/development-deployment.md`](../docs/development-deployment.md);
- ranh giới toàn hệ thống: [`../docs/architecture-overview.md`](../docs/architecture-overview.md).

Dependency, runtime và scripts lấy từ [`package.json`](package.json) cùng `pnpm-lock.yaml`. Mọi lệnh
phải chạy trong `frontendv2/`; bundle deploy đã sinh không phải source of truth.
